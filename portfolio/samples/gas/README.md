# GAS（Google Apps Script）自動化サンプル

ポートフォリオ用の見本コード。それぞれ**別のスプレッドシート（別プロジェクト）**に貼り付けて使う。

| ファイル | できること | 想定する依頼 |
|---|---|---|
| `form-autoreply.gs` | Googleフォームの回答者へ自動返信メール、担当者へ通知、対応状況を記録 | 問い合わせ・予約・申込の自動化 |
| `daily-summary.gs` | 毎朝、前日の売上をカテゴリ別に集計してSlackまたはメールに送信 | 日報・売上報告の自動化 |
| `invoice-pdf.gs` | 請求先リストから請求書PDFを一括作成し、Googleドライブに保存 | 月末の請求書作成の自動化 |

- 動作確認：`daily-summary.gs` はGASのAPIを模したテスト環境で集計結果を確認済み。他の2本は文法チェック済みで、本番の動作確認は実際のスプレッドシートで行う。
- 本番納品時は、お客様のシート構成に合わせて列名・セル位置を調整し、使い方マニュアルをつける。
