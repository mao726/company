# データ整理サンプル（作業代行の見本）

`before.csv`（よくある「バラバラな表」）を `after.csv`（そのまま使える表）に整えた例。

| 整えたこと | 例 |
|---|---|
| 全角・半角の統一 | `ｶﾌｪ` → `カフェ`、`Ａｏｉ` → `Aoi`、`１－２－３` → `1-2-3` |
| 重複の統合 | 表記ゆれのある同じ店舗2行を1行に |
| 住所の分割・補完 | 都道府県／市区町村／番地に分け、欠けている都道府県を補完 |
| 電話番号の形式統一 | `(012)3456780` → `012-345-6780` |
| 営業時間の分解 | `10時から20時 火曜定休` → 開店・閉店・定休日の列へ |
| 空行の削除 | 空の行を削除 |

実際の作業では、処理内容を備考列に残し、判断に迷う箇所はお客様に確認してから確定する。
