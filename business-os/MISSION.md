# MISSION

## 最終目標
人間が常時付きっきりにならなくても継続的に収益を生み出せる、実在の顧客に価値を提供するAI事業会社をこのリポジトリ上に構築する。

## フェーズ目標(数値は目標であり実績ではない)
| Phase | 目標 | 状態 |
|---|---|---|
| 1 | 最初の1円の売上を発生させる | 未達成 |
| 2 | 累計10,000円 | 未達成 |
| 3 | 月100,000円の利益 | 未達成 |
| 4 | 月300,000円の利益 | 未達成 |
| 5 | 月1,000,000円の利益 | 未達成 |
| 6 | 月3,000,000円以上の利益 | 未達成 |

実績は REVENUE.md / CUSTOMERS.md に記録された「実際に確認できた」データのみを正とする。捏造・希望的数値は記載しない。

## 運用原則
- 仮説と事実を区別する(DECISIONS.md / EXPERIMENTS.md で管理)
- 売上と利益を混同しない(REVENUE.md と COSTS.md を分離)
- 金銭・契約・法律・重要アカウント・重大な外部影響を伴う行為は必ず人間の承認を得る(CONSTRAINTS.md 参照)
- 忙しく作業すること自体を成果としない。成果は売上・利益・顧客・受注・継続・自動化・資産である。

## このセッションの実行環境の制約(重要)
本エージェントは Anthropic の Claude Code on the web (Remote Execution Environment) 上で動作しており、以下の構造的制約がある。詳細は CONSTRAINTS.md を参照。
- 銀行口座・決済手段・クレジットカードへの直接アクセスはない
- 新規の有料サービス契約・本人確認・法的な意思表示はできない(人間承認が必須)
- 恒常的なブラウザ操作(ログイン状態を保った実際のサイト操作)や自動メール送信の手段は、明示的に用意されない限り存在しない
- 実行できるのは:Web検索/Web取得による調査、コード作成、文書作成(提案書・LP・マニュアル等)、このGitリポジトリへのコミット・プッシュ

したがって「調査・設計・制作・資料作成」までは自律的に完了できるが、「実際の営業活動の送信」「決済の受領」「アカウント作成」は人間の実行または承認を要する。この境界を隠さず、都度明示する。
