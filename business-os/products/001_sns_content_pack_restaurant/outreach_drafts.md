# 拡散・営業文面ドラフト(人間が送信/投稿する用)

このAIエージェントにはSNS投稿・メール送信の手段がないため、以下は下書きのみです。実際の投稿・送信は人間が行ってください(内容は自由に調整して構いません)。

## 1. 自分のSNS(X/Instagram等)でnoteを紹介する場合

```
飲食店・カフェのオーナーさん向けに「SNSのネタ切れを防ぐ30日分テンプレート+AIプロンプト集」をまとめました。
毎日の投稿、何を書くか迷わなくなります。よければ見てみてください。
[note記事のURL]
```

## 2. 知り合いの個人店オーナーに直接勧める場合(紹介・直接営業)

```
【店名】さん、いつもお世話になっています。
SNSの投稿、ネタが尽きて大変なタイミングがあると思ったので、飲食店向けに「1ヶ月分の投稿ネタ+テンプレート」をまとめたものを作りました。
500円のnote記事にしていますが、もしよければ一度サンプル(無料部分)だけでも見てもらえたら嬉しいです。感想があれば率直に教えてもらえると助かります。
[note記事のURL]
```

ポイント:
- 誇張しない、実績を偽らない(「バズります」等は書かない)
- 相手に見返りを強要しない(「感想を教えてほしい」程度に留める)
- 最初の1件は「販売」より「率直なフィードバック」を得ることを優先する(価格や内容の妥当性を検証するため)

## 3. 無料相談・診断のオファー(将来のA案:SNS部分代行への展開用、必要なら)

```
【店名】さんのInstagram、拝見しました。もしよければ、投稿ネタに困っていないか、無料で1回分だけ投稿ネタ案を作ってお送りすることもできます。気に入っていただけたら継続のご相談もできればと思います。ご迷惑でなければぜひ。
```

これは今回の実験(note販売)の結果を見た後、必要であれば使用してください。
