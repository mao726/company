# 商品001: 個人経営の飲食店・カフェ向け「SNS投稿ネタ30日テンプレート集」

## ターゲット
個人経営〜小規模の飲食店・カフェのオーナー/店長。SNS担当者を雇う予算がなく、自分で投稿しているが「ネタが尽きる」「毎日何を投稿すればいいか分からない」と感じている層。

根拠: research/2026-09-18_market_scan.md の調査で、企業のSNS担当者の43.0%が「話題性の高いネタを提供できない」、41.1%が「SNSに詳しい担当者がいない」と回答(ニュートラルワークス調査)。SNS運用の丸ごと代行は月5万円以上が相場で、個人店には導入しづらい価格帯。

## 商品コンセプト
「丸ごと代行」ではなく、**オーナー自身が投稿を続けられるようにする「ネタ切れしない仕組み」を売る**。テンプレート+AIプロンプト集で、ChatGPT/Claude等に貼るだけでキャプションが作れるようにする。

## 価格
500円(初回投稿・実績ゼロの段階では購入ハードルを下げることを優先。捏造した「相場」を書かず、実際にこの価格で試す)。

## 提供形態
note(または BOOTH)での有料記事として販売。無料部分で価値を示し、有料部分で30日分のテンプレート本体を提供する構成(note_article.md参照)。

## 人間に依頼したいアクション(承認/実行が必要)
1. note(https://note.com)の無料アカウントを作成する(法人・個人事業主どちらでも可。売上受取のため銀行口座情報の登録が必要)。
2. note_article.md の内容をnoteの記事エディタに貼り付ける。
3. 有料エリアの価格を500円に設定して公開する。
4. 公開後のURLをこのフォルダに記録する(PROGRESS.md / SALES_PIPELINE.md に追記します)。

上記が完了すれば、実際の販売開始(=Phase 1の検証開始)となります。売れた場合のみREVENUE.mdに記録します。捏造はしません。
