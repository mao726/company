# 定期報告フォーマット(これだけ教えてもらえればOK)

数字が分かる範囲でいいので、そのまま貼ってください。分からない項目は空欄/「不明」で構いません。憶測や既存の数字の使い回しはしません。

```
日付:
note全体ビュー(閲覧数):
noteスキ数:
note購入数/売上:
noteコメント(あれば内容も):
X フォロワー数:
X 投稿への反応(いいね/RT等、自動化開始後):
知人・紹介での反応(あれば):
その他気づいたこと:
```

## 確認方法の場所
- note: プロフィールアイコン(右上)→ダッシュボード、または記事ページ上部の数字表示
- X: プロフィール画面のフォロワー数、各投稿の下のいいね/リポスト数

## このファイルの使い方
- 毎回全項目を埋める必要はありません。分かる範囲だけで大丈夫です。
- 報告いただいた内容は、そのまま KPI.md / EXPERIMENTS.md / SALES_PIPELINE.md に反映します。
- 推測や「たぶんこれくらい」という数字は、事実として記録しません(その場合は「推定」と明記して分けて記録します)。
