# CONSTRAINTS — 利用可能な環境・ツール・制約(STEP1〜4)

最終更新: 2026-09-18

## STEP1: 環境調査
- 実行場所: Claude Code on the web の Remote Execution Environment(コンテナ、セッション終了で消滅)
- リポジトリ: github.com/mao726/company (プライベート想定、空リポジトリから開始)
- OS: Linux, root権限あり
- ツール: git, node v22, npm, python3, pip3, curl
- 利用可能な追加ツール(このエージェント経由):
  - WebSearch / WebFetch(市場調査・競合調査に使用)
  - GitHub MCP(Issue/PR操作、このリポジトリのみ)
  - ファイル作成・コード実行(Bash, サンドボックス内)
- 利用不可(このセッションには存在しない):
  - 実ブラウザでのログイン操作(Claude in Chrome 等の拡張はこの環境には接続されていない)
  - メール送信手段
  - 決済・銀行・クレジットカードAPI
  - SNSアカウントへの投稿権限
  - クラウドソーシングサイトへの出品・応募権限(アカウント未作成)

## STEP2: できること / できないこと
### できること(自律実行可)
- Web検索による市場調査・競合調査・価格調査
- 事業計画・商品設計・価格設計の文書化
- LP(ランディングページ)・提案書・営業文面・マニュアル・FAQの制作(コード/文書)
- 実際に納品可能なデジタル成果物の試作(記事、コード、スプレッドシート雛形、分析レポート等)
- 業務フロー設計、自動化スクリプト作成
- 進捗・意思決定・実験結果の記録

### できないこと(人間の実行・承認が必須)
- 有料サービスの契約、サブスク登録
- 銀行口座・決済手段(Stripe/PayPal等)の開設・連携
- クラウドソーシング(ランサーズ、ココナラ、Upwork等)への実際のアカウント作成・出品・応募
- 実際の顧客への営業メール・DM送信(送信手段が存在しないため、文面のドラフトまでが可能)
- SNSアカウントの作成・投稿(投稿文の作成までが可能)
- 本人確認、税務・行政手続き

## STEP3/4: 必要なツールの分類
| ツール/行為 | 分類 | 備考 |
|---|---|---|
| Web検索・調査 | 無料・自律可 | 実施中 |
| LP/コード制作 | 無料・自律可 | このリポジトリ内で実施 |
| クラウドソーシング出品(ランサーズ等) | 人間承認必要 | アカウント作成・本人確認を伴う |
| Stripe/PayPal等決済 | 人間承認必要 | 金銭・契約 |
| SNS運用代行の実施 | 人間承認必要(実行フェーズ) | 対象企業との契約が先に必要 |
| 有料ツール・広告 | 人間承認必要 | 費用発生 |

## 結論
このセッション単独で「実際の受注・決済」までを完了することは、外部アカウント・決済手段が存在しない限り不可能。
したがって最初の実験は、**人間が最小限のアクション(アカウント作成、決済受領などの1タップ〜数タップの承認)で完了できる形**に商品・営業導線を設計し、調査・設計・制作はすべて自律で完了させる方針とする。
