# 振り返り（改善サイクル）

## 1. 記録する（毎回）

`docs/lessons/log.md`（リポジトリ外なら `~/.claude/lessons/log.md`）の表に1行追加する。

| 列 | 書くこと |
|---|---|
| 日付 | YYYY-MM-DD |
| 起きたこと | 事実だけを1文で（誰の責任かは書かない） |
| 原因 | 「なぜ」を2〜3回たどった根本原因 |
| 直したこと | 実際に行った修正 |
| 再発防止策 | 次に同じ状況で何をするか（行動で書く） |
| 回数 | 同じ種類の失敗が過去にあれば、その行の回数を増やす（新しい行を作らない） |
| 反映先 | 未反映／CLAUDE.md／スキル名 |

同じ種類かどうかは「再発防止策が同じになるか」で判断する。

## 2. 反映するか判断する

次の3つを**すべて**満たす時だけ、CLAUDE.md かスキルに反映する。

1. 回数が2回以上
2. 特定の案件だけでなく、他の作業にも当てはまる
3. 再発防止策を実際に試して、効果を確認できた

満たさないものは記録に残すだけにする（毎回読み込む情報を増やさないため）。

## 3. 反映する時のルール

- CLAUDE.md は60行以内を保つ。追加する時は、古くなった行・重複した行を削れないか先に確認する。
- 1つの学びは1〜2行で、行動として書く（「気をつける」ではなく「〜を確認してから〜する」）。
- 特定の作業手順に関する学びは、CLAUDE.md ではなく該当するスキルに書く。
- 反映したら、記録の「反映先」を更新する。
- 反映した変更は、ユーザーへの報告に1行で書く。
