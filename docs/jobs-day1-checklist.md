## B. 明日の昼、PCでオーナーがやること（申請3：約20分）

目的：ジョブスが**あなたのChrome（ログイン済みの状態）を操作**して、プロフィール入力・出品・応募をできるようにする。

1. **Claudeデスクトップアプリを入れる**：claude.com/download からダウンロード → インストール → このアカウントでログイン
2. **Chromeに拡張機能「Claude」を入れる**：Chromeウェブストアで「Claude in Chrome」を検索 →「Chromeに追加」→ 拡張機能でも同じアカウントでログイン
3. **Chromeで各サイトにログインしておく**：ココナラ・クラウドワークス・ランサーズ・Gmail（ログインはオーナーが行う。パスワードはジョブスに教えない）
4. **デスクトップアプリで作業用セッションを作る**：上部の「Code」タブ →「+ New session」→ 実行場所は **Local（このPC）** を選ぶ → フォルダはデスクトップに作った空のフォルダ（例：`jobs`）でOK
5. **最初のメッセージに下の「引き継ぎ文」を貼って送る**
6. ブラウザ操作の許可を聞かれたら「許可」（サイトごとに確認が出る）

### 引き継ぎ文（そのまま貼る）

> あなたは「ジョブス」として、私の副業ビジネスを運営します。計画と文面はGitHubの mao726/company リポジトリ、ブランチ claude/line-stamp-sales-analysis-cwvffb の docs/ にあります（jobs-30day-plan.md、jobs-sales-kit.md、jobs-day1-checklist.md、jobs-market-research.md）。まずそれを読み、Claude in Chrome で私のChromeを使って、チェックリストの「C. 明日ジョブスがやること」を進めてください。顧客への送信・応募・支払いは、送る前に必ず私に確認してください。

- うまくつながらない時：セッションで `/chrome` と送ると接続状態を確認・再接続できる。それでもダメならChromeとアプリを再起動。
- 必要なもの：Chrome（またはEdge）、Pro以上のClaudeプラン。
