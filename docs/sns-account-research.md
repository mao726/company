# 同ジャンル成長アカウント調査（40〜58歳向け／楽天アフィリエイト×食品・ファッション・美容・雑貨）

調査日：2026-09-28
方法：Web検索によるリサーチ（一次情報の直接分析ではなく、公開記事・ノウハウ記事のまとめ）

## 1. 楽天ROOM単体の力学

- フォロワーが増えるほどランキング上位に入りやすく、露出増→さらにフォロワー増という好循環が生まれる
- ただしROOMは基本的に「フォロワー」または「いいねし合った相手」にしか投稿が届かない仕組みのため、**外部SNSからの流入が成長の生命線**になる

## 2. Threads×楽天ROOMの組み合わせが有効な理由

- ThreadsはROOMと異なり、フォロワー0でも「面白い」と判定されれば非フォロワーのタイムラインにも配信されるアルゴリズムを持つ。ROOM単体よりリーチが伸びやすい
- 王道パターン：ROOMに商品リンクを作成 → Threadsで日常のストーリー仕立てで紹介 → プロフィールリンク／ピン留め投稿からROOMへ誘導。商品紹介だけでなく日常投稿を混ぜることで信頼を積む
- 現実的な期待値：月数千〜数万円が大半。月10万円超の事例は「他SNSで元々フォロワーを持っていた人」が中心で、ゼロから即座にバズるケースは稀

## 3. 商品選定・投稿タイミングの傾向

- 「悩みを解決する」商品が刺さりやすい（収納・時短・体型カバーなど）。人は悩みの解決にお金を払う傾向がある
- 母の日・クリスマス・年末年始・新生活シーズンなど季節行事に合わせた紹介が反応が良い
- 楽天スーパーセール／お買い物マラソンのタイミングは特にフォロワーが伸びやすい絶好機

## 4. 顔出し・個人ブランディングが効く理由

- 複数の情報源で共通していた指摘：「ファンは商品ではなく“人”につく」
- 完璧に作り込んだ発信より、等身大・人間味のある発信の方が共感を集めやすい
- ストーリーズの質問・アンケート機能などの双方向コミュニケーションが、ファン化・ロイヤルティ向上に直結する
- 統一感のあるブランディングと独自のコンセプトの継続が差別化につながる

### 参考になる成長アカウントの傾向
- **bon_pon夫妻（60代夫婦、フォロワー80万人超）**：日々のファッションコーディネートを本人たちが発信。「その人自身の日常・価値観」が軸になっている
- **40〜50代ファッション系インスタグラマー複数（田丸麻紀氏、犬山紙子氏など）**：洗練されたコーデ発信だけでなく、等身大の葛藤や喜びを発信するアカウントも人気
- 共通点：**プロが作ったような完璧さよりも、同世代としての共感・リアリティが支持される**

## 5. 楽天ROOMのプロフィール設計の実践的コツ

- **ユーザー名**：上位ユーザーの9割以上が「4文字以下」の短くユニークな名前を使用。覚えやすさが重要
- **アイコン**：「自分の顔」に相当する要素。似顔絵イラストか本人写真が推奨される
- **プロフィール文**：基本ステータス（何者か、何を紹介するか）を簡潔に
- **ヘッダー画像**：「お店の看板」的役割。アカウントの世界観を決める重要な1枚

## 6. 今回の方針への反映

今回決定した「**かおり個人としてファンをつける／アイコンは本人写真**」という方向性は、上記の調査結果（顔出し・個人ブランディングの有効性、楽天ROOMのアイコン推奨事項）と合致している。

これを踏まえ、以下を反映する：
- プロフィール上の主語を「アカウント名（キュレーター的な立ち位置）」から「かおり」という個人名に変更
- アイコンをロゴ・イラストではなく本人写真に設定
- 投稿トーンも「お店からのお知らせ」ではなく「かおり個人の日常・実体験」を軸にする
- Threadsを軽視せず、ROOMへの導線役として積極活用する（日常投稿×商品紹介の織り交ぜ）
- 商品選定は「悩み解決」軸・季節行事連動を優先する
