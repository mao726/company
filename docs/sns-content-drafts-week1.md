# 投稿文案サンプル（1週間分）｜かおり アカウント

対象：X（1日3投稿）／Threads（1日3投稿）／Instagram（週3投稿）
方針：商品・アフィリエイトの選定は別途決定するため、ここでは**かおりの日常・つぶやき**のみを扱う。商品を絡める回が決まったら、該当の投稿に差し込む形で調整する。
トーン：同世代の友人に話しかけるような、等身大・自然体（過度な絵文字・煽り文句は避ける）

投稿時間の目安：**朝（7〜9時）／昼〜夕方（12〜17時）／夜（21〜23時）**

## 月曜日

3. 夜：`月曜日、なんだかんだで無事終了。お風呂上がりにこれを書いてます。今週もゆるく頑張りましょう。`

## Instagramストーリーズ（1日3回）

Instagramのフィードは文章だけの投稿ができない仕様のため、X/Threadsと同じ日常つぶやきは**ストーリーズ**で運用する。
やり方：単色背景＋テキストのストーリーズ機能を使い、その日のX（またはThreads）の投稿文をそのまま貼り付ける。3投稿とも同じ内容を使い回してよい（媒体ごとに文章を変える必要はない）。
余裕があれば、質問スタンプ・投票スタンプを1つ添えるとフォロワーとの双方向のやり取りが生まれやすい。

## Instagramフィード（週3投稿）

### 投稿1（火曜想定）
**画像イメージ：** 朝の食卓やコーヒーなど、日常のワンシーン
**キャプション：**
```
おはようございます、かおりです。
最近、朝のコーヒーをゆっくり淹れる時間がお気に入り。
たった5分だけど、一日の始まり方が変わる気がしています。

みなさんの朝のちょっとした習慣、よかったら教えてください☺️
```

### 投稿2（木曜想定）
**画像イメージ：** 近所の風景、季節を感じるもの（空・植物など）
**キャプション：**
```
いつもの道なのに、季節が変わると景色まで違って見える気がします。
忙しい毎日の中でも、こういう瞬間をちゃんと見逃したくないなと。

今日も一日お疲れさまでした🌿
```

### 投稿3（土曜想定）
**画像イメージ：** 休日の暮らしのワンシーン（家族・食卓・部屋など）
**キャプション：**
```
休日は予定を詰め込まず、だらだら過ごすのが好きです。
何もしていないようで、実は一番贅沢な時間かもしれません。

みなさんは休日、どんな風に過ごしていますか？
```

## 運用メモ

- 上記はあくまで**トーン・型を示すサンプル**。実際の投稿は当日の天気・出来事に合わせて内容を調整する
- 商品紹介を挟む回が決まったら、該当の時間帯の投稿を日常投稿→商品紹介＋PR表記付き投稿に差し替える（1日3投稿のうち1枠を商品紹介に充てる運用を想定）
- フォロワーからの反応（いいね・コメント・保存）が良かったテーマ・時間帯は都度メモし、翌週以降の投稿に反映する
