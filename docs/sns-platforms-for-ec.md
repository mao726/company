# 主要SNS一覧（EC事業関連）

EC（Eコマース）事業のマーケティング・集客・販売チャネルとして関係してくる主要SNSプラットフォームをまとめる。

## グローバル系SNS

| SNS | 概要 | EC関連機能・活用ポイント |
|---|---|---|
| **Instagram** | 写真・動画中心のビジュアルSNS。若年〜中年層に強い。 | ショッピングタグ、Instagramショップ、リール広告、インフルエンサーマーケティング、ライブコマース（Live Shopping） |
| **Facebook** | 実名制の総合SNS。幅広い年齢層。 | Facebookショップ、Marketplace、Meta広告（Instagramと連携運用が多い）、コミュニティグループ経由の販促 |
| **TikTok** | ショート動画SNS。Z世代を中心に急拡大。 | TikTok Shop、ハッシュタグチャレンジ、UGC/インフルエンサー施策、ライブコマース |
| **X（旧Twitter）** | テキスト中心の即時性の高いSNS。 | 拡散・口コミ形成、キャンペーン告知、ショッピング機能（一部地域）、カスタマーサポート窓口 |
| **YouTube** | 動画プラットフォーム。 | YouTubeショッピング（商品タグ）、レビュー動画・アンボックス動画による購買喚起、ライブ配信販売 |
| **Pinterest** | 画像ブックマーク型SNS。購買意欲の高いユーザーが多い。 | 商品ピン（Product Pins）、購入直結の広告フォーマット、インテリア・アパレル・ギフト系ECと相性良好 |
| **Threads** | Meta運営のテキストSNS（Instagram連携）。 | 現状ショッピング機能は限定的だが、ブランド発信・コミュニティ形成チャネルとして活用増加中 |
| **Snapchat** | 若年層向けメッセージ・ARSNS。 | ARフィルターを使った試着・試用体験、Snapチャットショッピング広告 |
| **WhatsApp（Business）** | メッセージアプリ。 | WhatsApp Business API経由での注文受付・カスタマーサポート、カタログ機能 |
| **Reddit** | 掲示板型コミュニティSNS。 | 特定ニッチ商材のコミュニティマーケティング、口コミ形成 |

## 日本国内で特に重要なSNS

| SNS | 概要 | EC関連機能・活用ポイント |
|---|---|---|
| **LINE** | 日本国内最大級のメッセージアプリ。 | LINE公式アカウント、LINEショッピング、LINEギフト、クーポン配信、リッチメニューからの誘導、LINE広告 |
| **Instagram（国内）** | 日本でも特にEC親和性が高い。 | 上記に加え、国内ブランドのショップ開設が非常に活発 |
| **X（国内）** | 日本語圏で利用率が高い。 | プレゼント企画・拡散施策、フリマ系との連携も多い |

## アジア圏の主要SNS（越境EC・インバウンド向け）

| SNS | 概要 | EC関連機能・活用ポイント |
|---|---|---|
| **WeChat（微信）** | 中国最大のスーパーアプリ。 | WeChat Mini Program（ミニプログラム）でのEC構築、WeChat Pay連携、公式アカウント経由の販促 |
| **Xiaohongshu（RED/小紅書）** | 中国のライフスタイル系SNS。EC機能内蔵。 | インフルエンサー（KOL）マーケティング、アプリ内購入機能、越境ECとの親和性が高い |
| **Weibo（微博）** | 中国版Twitter的SNS。 | KOLマーケティング、キャンペーン拡散 |
| **KakaoTalk** | 韓国最大のメッセージアプリ。 | Kakaoショッピング、トークチャネル経由の販促 |
| **Naver（ブログ／カフェ）** | 韓国の検索・SNSプラットフォーム。 | Naverショッピング連携、口コミ形成 |
| **Douyin（抖音）** | TikTokの中国国内版。 | ライブコマースが非常に発達、EC連携が強力 |

## ライブコマース・特化型プラットフォーム

- **TikTok Shop / Douyin**：ライブ配信からの即時購入が主流化
- **Instagram Live Shopping**
- **YouTube ライブショッピング**
- **タオバオライブ（淘宝直播）**：中国最大級のライブコマース市場

## EC事業での活用フェーズ別まとめ

- **認知獲得**：Instagram、TikTok、YouTube、X
- **購買意欲醸成・比較検討**：Pinterest、YouTube（レビュー）、Xiaohongshu
- **直接購入（ソーシャルコマース）**：Instagramショップ、TikTok Shop、Facebookショップ、WeChatミニプログラム
- **顧客対応・リピート施策**：LINE公式アカウント、WhatsApp Business、X（サポート窓口）
- **越境EC・インバウンド**：WeChat、Xiaohongshu、Weibo、KakaoTalk、Naver

---
補足：各SNSのショッピング機能・広告仕様は頻繁にアップデートされるため、施策実行前に最新の公式ヘルプ・広告ガイドラインの確認を推奨する。
