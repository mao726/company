# ジョブス 事業計画（30日目標＋継続運用）

- 期間：2026-10-11（昼）〜 2026-11-09（30日）※10/10は調査・準備日
- 資金：10,000円
- 目標：最初の30日で利益 500,000円（複数事業の合計）。**以降も継続する事業**として、毎月の利益が積み上がる形を優先する
- 役割：考える・作る・運用するのはジョブス（Claude）。オーナーは申請された権限の付与・本人名義の登録・1日30分程度の承認/連絡。

## 0. 前提と正直な見通し

- 資金1万円では広告・仕入れ型（物販・ドロップシッピング）は伸ばせない。**ジョブスの作業量をそのまま売上にできる「受託」を本命**にする。
- 新規アカウントは実績（評価）ゼロのため、**最初の1〜2週間は受注しにくい**。初週は実績づくり（ポートフォリオ＋お試し価格）に集中する。
- 現実的な見込み：**30日で5〜20万円が堅実ライン、50万円は上振れシナリオ**。達成に向けて全力は出すが、約束はしない。
- やらないこと：迷惑メール・スパム営業、やらせ評価、誇大広告、各プラットフォームの規約違反、AI生成イラストの販売（ココナラは原則禁止）。
- **AI活用は顧客に明示**する（サービス説明に「AIを活用して制作し、人が確認して納品」と記載）。

## 6. 継続を前提にした設計（30日以降）

30日の売上だけでなく、**翌月以降も積み上がる収入**を作ることを優先する。単発の受託は「入口」と位置づけ、継続収入へつなげる。

### 継続収入の柱

| 柱 | 内容 | 月額目安 |
|---|---|---|
| **保守・運用の月額契約** | 制作したサイトの更新・修正・軽微な改善、ツールの保守 | 3,000〜10,000円／社 |
| **定期作業の月額契約** | 毎月のデータ集計・レポート作成、ブログ記事の定期作成 | 1〜5万円／社 |
| **デジタル商品** | テンプレート・ツール・ノウハウ記事（作れば売れ続ける） | 少額×多数 |
| **自社集客の窓口** | 自社サイト・事例ページ・ブログからの直接依頼（手数料ゼロ） | — |

### 判断基準

- 受託案件は「納品後に月額契約へつながるか」を重視して選ぶ。
- 同じ種類の依頼が3回来たら、**テンプレート化・商品化**する（作業時間を減らし、利益率を上げる）。
- プラットフォーム手数料を下げるため、評価が貯まったら自社サイト経由の直接受注を増やす（各プラットフォームの直接取引に関する規約は守る）。

### 中期目標（目安）

| 時期 | 目標 |
|---|---|
| 1ヶ月目 | 実績・評価をつくる。単発の受託で売上を立てる |
| 2〜3ヶ月目 | 月額契約5社以上、デジタル商品5点以上、自社サイトからの問い合わせ開始 |
| 4〜6ヶ月目 | 継続収入だけで月10万円以上。売れる型をパッケージ化 |
| 以降 | 開業届・会計（freee等）を整え、事業として正式に運用 |

### 継続運用のしくみ

- 毎朝の自動実行（スケジュール）で、案件チェック・提案・日報更新を続ける。
- 月末に振り返り：事業ごとの利益・作業時間を比べ、伸びるものに集中し、伸びないものはやめる。
- 税金：所得が出たら確定申告が必要。会社員の副業なら、所得20万円以下でも住民税の申告が要る点に注意（年末までに整理する）。

## 6.5 90日で「毎月10万円」を作る継続事業（10/10 追加）

オーナー方針：成果が出るまで時間がかかっても、**90日以内に月10万円程度の利益**が見込めるものは取り入れてよい。

### 候補の評価

| 候補 | 90日で月10万円の見込み | 理由 |
|---|---|---|
| **F. 月額の運用代行**（LINE公式アカウント・SNS投稿・スプレッドシート運用・サイト更新） | **中〜高（採用）** | CrowdWorksに継続型の運用案件が常にある（応募5〜20人、月3〜15万円）。小規模店舗向けの相場は月1〜3万円。**月2万円×5社で達成**。受託の顧客からの切り替えも見込める |
| **G. 業務テンプレート・ツール販売**（BOOTH・note・ココナラのコンテンツ販売） | 低〜中（採用・補助） | 作れば売れ続ける資産になるが、BOOTHだけでスプレッドシート関連の出品が500件超あり、目立つまで時間がかかる。受託でよく出る依頼を商品化して、作業時間をかけずに積み上げる |
| SEOブログ・アフィリエイト | 低（見送り） | 検索で上位に出るまで通常6〜12ヶ月 |
| YouTube・ショート動画の収益化 | 低（見送り） | 収益化の条件（登録者・再生時間）を90日で満たすのは難しい。AIの量産動画は規約上のリスクもある |
| Kindle本の量産 | 低（見送り） | 1冊あたりの利益が小さく、AI生成の申告が必要。量産は品質面で逆効果 |
| 物販・せどり・ドロップシッピング | 低（見送り） | 資金1万円では仕入れも広告もできない |
| 補助金申請書・確定申告の作成代行 | **不可** | 有料での作成は行政書士・税理士の独占業務（法律違反になる） |
| フォロワー販売・自動DM・一斉送信 | **不可** | 各SNSの規約違反・迷惑行為 |

### F. 月額運用代行の設計

| メニュー | 内容 | 月額 |
|---|---|---|
| LINE公式アカウント運用 | 月4回の配信文作成・配信予約、リッチメニュー更新、反応の月次レポート | 15,000〜30,000円 |
| SNS投稿代行（文章中心） | Instagram・X・Threadsの投稿文を週2〜3本、予約投稿、月次レポート | 10,000〜30,000円 |
| スプレッドシート運用 | 毎月の集計・レポート作成、GASの保守・小改修 | 5,000〜20,000円 |
| サイト更新サポート | LP・ホームページの文言・画像差し替え（月◯回まで） | 3,000〜10,000円 |

- **集め方**：①CrowdWorks・ランサーズの継続型の運用案件に応募 ②ココナラに月額の出品を追加（[販売キット](./jobs-sales-kit.md)の出品D） ③受託の納品時に月額での継続を提案（プラットフォーム内で契約）
- **作業**：配信文・投稿文・レポートはジョブスが作成。アカウントの権限は顧客から「管理者・運用担当」として付与してもらう（パスワードは預からない）
- **画像**：顧客支給の写真、または自作のデザイン（AI生成画像は顧客の許可がある場合のみ）
- **マイルストーン**：30日で1〜2社、60日で3〜4社、**90日で5社以上（月10万円）**
