# ドロップシッピング調査

在庫を持たずにネットで物販する「ドロップシッピング」について、仕組み・収益性・主要サービス・法的リスクを整理し、自社で取り組むかどうかの判断材料とする。

> 前提：本資料はEC支援会社・プラットフォーム・法律事務所などの公開記事をもとにしている。利益率などの数値は各社の見解・推計であり、監査されたデータではない。料金・規約は変わりやすいため、利用前に各サービスの公式情報を確認すること。

## 1. 仕組み

```
お客様 ──注文・代金──▶ 自社ショップ ──発注（仕入値）──▶ サプライヤー
   ▲                                                    │
   └──────────── 商品を直送（自社名義で発送も可） ◀───────┘
```

- 自社は**集客と販売**だけを担い、在庫・梱包・発送はサプライヤーが行う。
- 利益＝販売価格 −（仕入値＋送料＋決済・モール手数料＋広告費）。
- 顧客との契約主体は**自社**。配送遅延・不良品・返品の対応責任は自社が負う。

### 似た形態との違い

| 形態 | 在庫 | 発送 | 商品 |
|---|---|---|---|
| **ドロップシッピング** | 持たない | サプライヤー | 既製品 |
| **プリントオンデマンド（POD）** | 持たない | 制作会社 | 自社デザインのTシャツ・グッズ等（受注後に制作） |
| **発送代行（フルフィルメント）** | 持つ（倉庫に預ける） | 代行会社 | 自社仕入品 |
| **通常の物販** | 持つ | 自社 | 自社仕入品 |

## 2. メリット・デメリット

| メリット | デメリット |
|---|---|
| 初期費用・在庫リスクがほぼゼロ | **利益率が低い**（下記） |
| 商品数を増やす・入れ替えるのが簡単 | 参入障壁が低く**競合だらけ**、価格競争になりやすい |
| 梱包・発送の手間がない | 品質・配送スピードを**自分で管理できない** |
| 小さく始めて需要検証ができる | クレーム・返品対応は自社が担う |
| | 海外仕入れは**配送が遅い**（国内客は速さ・返品のしやすさを重視） |

### 収益性の目安

- 粗利率：**10〜30%程度**とする記事が多い。
- 広告費を引いた純利益率：**5〜15%程度**という推計もある（ベンダー発の数値）。
- Temuなどの格安プラットフォームが消費者の価格感覚を下げており、汎用品の値付けはさらに厳しくなっている。
- 含意：**「よくある商品を安く売る」型はほぼ利益が残らない**。ブランド化・ニッチ特化・国内発送の速さなどで価格以外の価値を作れるかがカギ。

## 3. 主なサービス

### ショップ（販売側）

| サービス | 特徴 |
|---|---|
| **Shopify** | 世界標準。ドロップシッピング用アプリ（DSers、CJ連携、Shopify Collective 等）が豊富。月額約29ドル〜 |
| **BASE / STORES / Square** | 国内向けで手軽。STORESは特商法表記の住所・電話番号の非公開に対応、Squareはオリジナルグッズ系サービスと自動連携できるとされる |
| **楽天市場 / Yahoo!ショッピング** | 集客力は強いが出店コスト・規約が厳しい。無在庫販売の扱いは各モールの規約を要確認 |

### 仕入れ（サプライヤー側）

**国内**（配送が速く、国内客向き）

| サービス | 特徴 |
|---|---|
| **TopSeller** | 旧「もしもドロップシッピング」（2020年4月終了）の後継。約30万点、楽天・Yahoo!とCSV連携。無料プランあり（料金は記事によって異なるため公式で要確認） |
| **NETSEA（ネッシー）** | 国内最大級の卸サイト。登録・月額無料。ただし直送対応は出展者・商品ごとに異なる |
| **スーパーデリバリー** | 出展3,300社以上。一部の出展企業の商品で直送が可能 |
| その他 | 卸売ドットコム、卸の達人、シイレル 等 |

**海外**（安いが配送が遅い）

| サービス | 特徴 |
|---|---|
| **AliExpress** | 品ぞろえ最大・テスト販売向き。配送が遅く、人気商品は競合が多い |
| **CJdropshipping** | 倉庫・配送代行があり比較的速い |
| **Alibaba / 1688** | 本格的に量を売る段階での卸仕入れ |
| **Temu** | 公式にはドロップシッピング非対応。仕入れ先にするのは非推奨 |

## 4. 法的・実務上の注意点

- **特定商取引法**：ドロップシッピングも「通信販売」なので、事業者名・住所・連絡先・返品条件などの表記義務がある。「発送はサプライヤーだから」という責任転嫁はできない。
- **景品表示法**：誇大な効果表示・不当な二重価格表示に注意。サプライヤーの商品説明をそのまま転載するのは危険。
- **許認可が必要な商材**：食品・化粧品・医薬品・医療機器などは許可・届出が必要な場合がある。医薬品の無許可販売は違法。
- **コピー品・知的財産**：海外仕入れでは偽ブランド品・画像の無断使用が混ざりやすい。
- **製造物責任（PL法）**：輸入品では、輸入した事業者が「製造業者等」として責任を負う場合がある。自社がどこまで該当するかは取引形態によるため専門家に確認すること。
- **「ドロップシッピング副業」勧誘トラブル**：「サイトを作れば稼げる」と高額な初期費用を払わせる業者のトラブルが過去に多発しており、クーリング・オフを認めた判例（2011年 大阪地裁）もある。**「開業パッケージ」系の勧誘には注意**。
- **税金**：利益が出れば事業所得・雑所得として申告が必要。海外仕入れは輸入消費税・関税にも注意。

## 5. 自社で取り組む場合の進め方（案）

1. **ニッチを決める**：大手・格安サイトと価格で戦わない領域（趣味・専門用途・ギフト・特定の悩みの解決 等）。
2. **国内サプライヤーを優先**：配送の速さと返品対応のしやすさが日本の顧客には重要。
3. **必ずサンプルを取り寄せる**：品質・梱包・配送日数を自分で確認してから出品。
4. **ページは自社で作り直す**：説明文・写真・使い方で差別化（ここが付加価値になる）。
5. **集客チャネルを決める**：SNS（Instagram・TikTok）や既存の顧客基盤を活用（[主要SNS一覧](./sns-platforms-for-ec.md)参照）。
6. **小さくテスト**：数商品・少額広告で反応を見て、売れた商品だけ深掘り。
7. **売れたら在庫を持つ形へ移行**：売れ筋は自社仕入れや発送代行に切り替えると利益率を上げられる。
8. **オリジナル商品化**：PODやOEMでブランド化できれば価格競争から抜けられる（LINEスタンプ等のキャラクターをグッズ化するのも一案）。
