# プロフィール確定版｜かおり（コピペ用）

そのままコピーして各アカウントの設定画面に貼り付けられる形にまとめたもの。
`【要入力】`となっている箇所のみ、実際の値を確定させてから入力する。

---

## X（旧Twitter）

**名前（表示名）**
```
かおり｜40代からのくらし発見
```

**プロフィール文**
```
かおりです。40〜50代の暮らしに役立つ、食品・ファッション・美容・生活雑貨を紹介しています。
実際に自分で使ってよかったものだけを発信中。
楽天のお得情報やセールもお知らせします。
※紹介リンクは楽天アフィリエイトを含みます（PR）
```

**アイコン**
`【要入力】` 本人写真（自然な笑顔・清潔感のある1枚。3媒体共通で使用）

**ヘッダー画像**
`【要入力】` 未定であれば単色背景でも可（後日差し替え前提でOK）

**ウェブサイト欄**
`【要入力】` 楽天ROOM等のリンク

**場所**
空欄でOK（個人発信のため所在地は不要）

## Instagram

**名前欄（表示名）**
```
かおり｜40代からのくらし発見
```

**ユーザーネーム（第一候補〜第三候補、空き状況に応じて選択）**
```

第二候補：kaori.kurashi40
第三候補：kaori_kurashi_40
```
`【要確認】` Instagramアプリ上で空き状況を確認し、使えるものを選択する

**プロフィール文**
```
かおり｜40〜50代の暮らしに役立つものを発見・紹介
🍽️食品・グルメ　👗ファッション　💄美容・健康　🏠生活雑貨
自分で使ってよかったものだけ厳選
```

**アイコン**

**リンク欄**
`【要入力】` 楽天ROOM等のリンク

クリエイター／個人ブログ（ビジネスプロフィールのカテゴリ選択時）

## 設定前チェックリスト

- [ ] 本人写真を1枚選定し、3媒体すべてのアイコンに設定（同一画像で統一）
- [ ] 楽天ROOM（または他の紹介リンクまとめ）を開設し、URLを確定
- [ ] Instagramユーザーネームの空き状況を確認し、上記候補から確定
- [ ] 各アカウントに上記プロフィール文をそのまま貼り付け
- [ ] Xのヘッダー画像・Instagramのハイライトカバー等は後日調整でOK（プロフィール文言確定を優先）

## 完了後の次のステップ

1. `docs/sns-content-drafts-week1.md` を使って初回1週間の投稿を開始
2. 各アカウントの初回投稿（自己紹介ポスト）をプロフィール確定後に投稿
3. フォロワー・反応の様子を見ながら、投稿トーンや頻度を調整
