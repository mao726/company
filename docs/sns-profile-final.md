# プロフィール確定版｜かおり（コピペ用）

そのままコピーして各アカウントの設定画面に貼り付けられる形にまとめたもの。
`【要入力】`となっている箇所のみ、実際の値を確定させてから入力する。

---

## X（旧Twitter）

**名前（表示名）**
```
かおり｜40代からのくらし発見
```

**プロフィール文**
```
かおりです。40代からの暮らしに役立つ、美容・料理・食器・インテリア・健康・ファッションのことを紹介しています。
実際に自分で使ってよかったものだけを発信中。
楽天のお得情報やセールもお知らせします。
※紹介リンクは楽天アフィリエイトを含みます（PR）
```

**アイコン**
設定済み（本人写真）

**ヘッダー画像**
`【要入力】` 未定であれば単色背景でも可（後日差し替え前提でOK）

**ウェブサイト欄**
空欄でOK（プロフィールに固定リンクは置かず、商品ごとにアフィリエイトリンクを投稿内で貼る運用）

**場所**
空欄でOK（個人発信のため所在地は不要）
