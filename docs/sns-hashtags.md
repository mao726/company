# ハッシュタグセット｜かおり アカウント

投稿本文とあわせて使うハッシュタグをまとめたもの。媒体ごとに使う本数・使い方の作法が異なるため、分けて記載する。

## 共通の基本ルール

- **PR表記は必須**：商品・アフィリエイトリンクを含む投稿には、必ず以下のいずれかを入れる（景品表示法対応）
  ```
  #PR　#広告　#楽天アフィリエイト
  ```
- 日常・つぶやき投稿（商品を含まない回）にはPR表記は不要
- ハッシュタグは詰め込みすぎず、投稿の内容に合ったものだけを選ぶ

---

## 1. X（旧Twitter）

Xはハッシュタグを多用すると読みにくくなるため、**1〜3個程度**に絞る。

**日常投稿用（共通で使えるベース）**
```
#40代
#アラフィフ
#丁寧な暮らし
```

**商品紹介投稿用（上記に追加）**
```
#PR
#楽天アフィリエイト
#楽天お買い物マラソン（セール時期のみ）
```

**ジャンル別（該当するものだけ1つ追加）**
```
美容：#40代美容
料理：#おうちごはん
食器：#うつわ好き
インテリア：#暮らしを整える
健康：#健康習慣
```

---

## 2. Threads

Threadsはハッシュタグ文化がXほど定着していないため、**0〜2個程度**、本文に自然に溶け込む形が望ましい。

**日常投稿用**
```
#40代の暮らし
#アラフィフ
```

**商品紹介投稿用**
```
#PR
#楽天アフィリエイト
```

---

## 3. Instagram

Instagramはハッシュタグの効果が高く、**8〜15個程度**を目安に、大小さまざまなタグを組み合わせる。

### 日常投稿用セット
```
#40代
#40代女性
#アラフィフ
#アラフォー
#丁寧な暮らし
#暮らしを楽しむ
#日々の暮らし
#大人女子
#40代の暮らし
#ゆるい暮らし
```

### 商品紹介投稿用セット（ジャンル別に組み合わせる）

**共通（必須）**
```
#PR
#楽天アフィリエイト
```

**美容**
```
#楽天コスメ
#40代美容
#スキンケア
#エイジングケア
#美容好きな人と繋がりたい
```

**料理**
```
#楽天グルメ
#おうちごはん
#簡単レシピ
#時短ごはん
#料理好きな人と繋がりたい
```

**食器**
```
#うつわ好き
#食卓
#うつわのある暮らし
#器好きな人と繋がりたい
```

**インテリア**
```
#楽天お買い物マラソン
#暮らしを整える
#部屋づくり
#インテリア好きな人と繋がりたい
#季節の模様替え
```

**健康**
```
#健康習慣
#40代の体調管理
#睡眠の質
#腸活
```

### 組み合わせ例（料理を紹介する投稿の場合）
```
#PR #楽天アフィリエイト
#40代 #アラフィフ #丁寧な暮らし #暮らしを楽しむ
#楽天グルメ #おうちごはん #簡単レシピ #時短ごはん
```

## 運用メモ

- 季節・セール時期（楽天スーパーセール、お買い物マラソン、母の日、年末年始など）は該当のタグ（`#楽天お買い物マラソン`等）を積極的に追加する
- 反応が良かった投稿のハッシュタグの組み合わせはメモしておき、次回以降に再利用する
- ジャンル別タグは今後の運用実績を見ながら随時追加・入れ替えていく
