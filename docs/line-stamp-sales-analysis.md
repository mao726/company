# LINEスタンプ 売れる／売れない分析

LINEクリエイターズスタンプ市場で「売れているスタンプ」と「売れていないスタンプ」の違いを整理し、自社で企画・改善するときの判断軸と、実売データを使った分析手順をまとめる。

> 前提：LINEは個別スタンプの販売数を公開していない。本資料は公開ランキングの傾向・クリエイターの公開事例・業界記事をもとにした定性分析である。自社の実売データ（クリエイターズマーケットの売上レポート）があれば、後半の手順で定量分析できる。

## 1. 市場構造（なぜ大半は売れないのか）

- **供給過多**：登録クリエイター・スタンプ数が非常に多く、「クリエイターの約9割は1つも売れたことがない」とする記事もある。
- **上位集中**：売上はランキング上位の一部に強く偏る（べき乗分布）。中位以下は「月数円〜数百円」の事例が多い。
- **収益の2本柱**
  - **買い切り販売**：ユーザーが個別に購入。
  - **LINEスタンプ プレミアム（サブスク）**：送信実績に応じて分配。分配式はおおむね「プレミアム売上総額 × 30% × （そのスタンプの送信ユーザー数 ÷ 全送信ユーザー数）」とされる。**「買われる」より「毎日送られる」ことが収益になる**構造。
- 含意：プレミアムの比重が大きい現在は、**日常会話で繰り返し使われる実用性**が以前にも増して売上に直結する。

## 2. 売れているスタンプの特徴

| 観点 | 売れているもの | 補足 |
|---|---|---|
| **用途** | 日常会話ですぐ使える（了解・ありがとう・おつかれ・ごめん・おやすみ 等） | 「使いどころを考えなくていい」ことが最重要 |
| **ターゲット** | 利用シーン・相手が明確（家族向け、ママ友向け、職場向けの敬語、カップル向け 等） | 「誰が誰に送るか」が一言で説明できる |
| **文字** | 大きく読みやすいセリフ入り、スマホの小サイズでも判読できる | 文字なしは用途が曖昧になりやすい |
| **画風** | シンプル／大人かわいい／ゆるい系。線が太く色数少なめ | 凝ったイラストより「見やすさ」 |
| **キャラクター** | 動物（特に猫・うさぎ・くま等）、表情の振れ幅が大きい | プレミアムでは猫キャラが強いという報告あり |
| **統一感** | 1セット内でキャラ・トーン・文字スタイルが揃っている | バラつくと「セット買い」の理由が弱まる |
| **シリーズ化** | 人気キャラの続編・敬語版・季節版・デカ文字版を展開 | 既存ファンが買い増す＝最も効率が良い |
| **季節・イベント** | 年末年始・誕生日・クリスマス・バレンタイン等 | 需要が確実で後発でも勝負しやすい。**1〜2ヶ月前**に公開 |
| **カスタム系** | 名前入り・カスタムスタンプ・メッセージスタンプ | 「自分用」の理由ができ購入動機が強い |
| **検索性** | タイトル・説明文・タグに検索される語（「敬語」「デカ文字」「猫」「毎日使える」等） | ストア内検索からの流入が大半 |
| **サムネイル** | メイン画像だけで「誰向け・何に使うか」が伝わる | 一覧で比較されるため第一印象で決まる |

## 3. 売れていないスタンプの特徴

| 症状 | 原因 | 改善策 |
|---|---|---|
| 使いどころが分からない | ネタ・一発ギャグ・作者の内輪ネタ中心 | 基本の挨拶・返事を8割、ネタは2割に |
| 小さく表示すると読めない | 細い線・小さい文字・色数が多い | 太線・大きな文字・背景とのコントラスト確保 |
| 誰向けか分からない | ターゲット未設定 | 「◯◯が◯◯に送る」を決めてから作る |
| 検索でヒットしない | タイトルがキャラ名のみ、説明文が抽象的 | 用途・属性ワードをタイトルと説明に入れる |
| セットの統一感がない | 思いついた絵を寄せ集め | トーン・文字スタイル・余白ルールを固定 |
| 1作で終わっている | シリーズ展開なし | 反応が良い作品の派生版を優先的に作る |
| 公開して放置 | 宣伝・導線がゼロ | SNS告知、既存作品の説明文から相互導線 |
| トレンドとずれている | 流行りの画風・言い回しを無視／逆に流行の後追いが遅すぎる | ランキングを定点観測し、定番×小さな新しさを狙う |

## 4. 企画チェックリスト（公開前）

- [ ] 「誰が・誰に・どんな場面で送るか」を一文で言える
- [ ] 40枚中、日常の定番返事（了解/OK/ありがとう/ごめん/おつかれ/おはよう/おやすみ 等）を十分に含む
- [ ] スマホ実機のトーク画面で縮小表示しても文字が読める
- [ ] メイン画像・タブ画像だけで用途が伝わる
- [ ] タイトル・説明文に検索されそうな語を入れた
- [ ] プレミアム（サブスク）対象に設定するか判断した（送信回数型の実用スタンプは対象にするのが基本）
- [ ] 季節物は1〜2ヶ月前倒しで申請した
- [ ] シリーズ展開（敬語版・デカ文字版・季節版）の構想がある

## 5. 自社データで定量分析する方法

クリエイターズマーケットの売上レポート（スタンプ別・月別の販売数／分配額、プレミアム分配）をCSVで用意できれば、以下で「売れる／売れない」を自社基準で切り分けられる。

### 用意するデータ（1行＝1スタンプ×1ヶ月）

| 列 | 例 |
|---|---|
| スタンプ名 / ID | ねこの毎日敬語 |
| 公開日 | 2025-11-01 |
| 月 | 2026-08 |
| 買い切り販売数・売上 | 12 / 1,440円 |
| プレミアム分配額 | 350円 |
| 属性タグ（手入力） | キャラ=猫, 文字=あり, 用途=敬語, 季節=なし, シリーズ=第2弾, 価格=120円 |

### 分析の手順

1. **ABC分析**：累計売上でスタンプを並べ、上位で売上の70%を占める群（A）と、ほぼ売れていない群（C）に分ける。
2. **属性比較**：A群とC群で属性タグの出現率を比較（例：「文字あり」がA群90%・C群40%なら強い要因）。
3. **ライフサイクル**：公開後の月別推移を見て「初速型（公開直後だけ売れる）」と「ロングテール型（プレミアムで長く稼ぐ）」を区別。
4. **買い切り vs プレミアム比率**：プレミアム比率が高い作品＝実際に送られている作品。次の企画の「型」にする。
5. **シリーズ効果**：続編公開月に前作の売上が伸びているか（相互送客）を確認。

データを渡してもらえれば、上記の集計・グラフ化まで実施可能。

## 6. 本資料に対する注意

- 個別スタンプの販売数はLINEが非公開のため、市場全体の「売れる／売れない」は推定を含む。
- プレミアムの分配ルール・価格帯・審査基準は変更されることがあるため、施策前に [LINE Creators Market](https://creator.line.me/ja/) の公式ガイドラインを確認すること。
