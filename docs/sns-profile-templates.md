# SNSプロフィール文言テンプレート（X／Threads／Instagram）

対象アカウント：新規開設した X（旧Twitter）、Threads、Instagram
ターゲット：40〜58歳
取扱ジャンル：食品・グルメ／ファッション・アパレル／美容・健康／生活雑貨・インテリア
ポジショニング：大人世代の暮らしに寄り添う「ライフスタイル選定ショップ」

> `[ブランド名]` `[URL]` `[エリア/所在地]` は仮のプレースホルダーです。ブランド名が決まり次第、該当箇所を差し替えてください。

## 共通の設計方針

- 一人語りの「私たちは〇〇です」ではなく、**何を扱い・誰の・どんな暮らしに役立つか**を最初の1文で明示する
- 複数ジャンルを扱う店なので、「セレクトショップ」「暮らしの，」という言葉で統一感を持たせる
- 絵文字は1〜2個までに抑え、年代に合わせて落ち着いたトーンにする
- 全アカウントでプロフィール文の核（コンセプト文）は統一し、媒体特性に合わせて末尾の一文だけ変える

## 4. アイコン・ヘッダー画像の統一方針（参考）

- **アイコン**：ロゴマーク or ブランドカラー1色の背景にロゴ文字（3媒体共通で同一画像を使用し、統一感を出す）
- **Instagramハイライトカバー**：「ご挨拶」「商品ジャンル別（食品／ファッション／美容／雑貨）」「よくある質問」「お客様の声」などをカテゴリ分け
- **Xヘッダー画像／Instagramのプロフィール直下ピン投稿**：自己紹介投稿を固定し、初訪問者が世界観を理解できるようにする
