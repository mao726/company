# SNSプロフィール文言テンプレート（X／Threads／Instagram）

対象アカウント：新規開設した X（旧Twitter）、Threads、Instagram
ターゲット：40〜58歳
取扱ジャンル：食品・グルメ／ファッション・アパレル／美容・健康／生活雑貨・インテリア
ポジショニング（フェーズ1）：**自社ショップではなく、楽天アフィリエイトで大人世代の暮らしに役立つ商品を紹介する個人（キュレーター）アカウント**
将来（フェーズ2）：フォロワーが育った段階で自社ECブランドへ移行予定

> `[ブランド名/アカウント名]` `[楽天ROOM等のリンク]` は仮のプレースホルダーです。名称・リンクが決まり次第、該当箇所を差し替えてください。
> フェーズ2で自社EC移行時は、末尾に「自社EC移行版プロフィール（案）」を参照し、差し替える。

## 共通の設計方針

- 「店」ではなく「一人の紹介者・キュレーター」としての一人称（「私」「〇〇（アカウント名）」）で発信する
- 何を紹介するアカウントか（40〜58歳向け・食品/ファッション/美容/雑貨）を最初の1文で明示する
- 絵文字は1〜2個までに抑え、年代に合わせて落ち着いたトーンにする
- 全アカウントでプロフィール文の核（コンセプト文）は統一し、媒体特性に合わせて末尾の一文だけ変える
- **アフィリエイト表記を必ず含める**：「PR」「楽天アフィリエイト」等の文言をプロフィール文またはリンク前に明記し、景品表示法（ステマ規制）に対応する

## 4. アイコン・ヘッダー画像の統一方針（参考）

- **アイコン**：顔出しなしで運用する場合はロゴ風アイコン、または統一感のあるイラスト・写真（3媒体共通で同一画像を使用）
- **Instagramハイライトカバー**：「ご挨拶」「ジャンル別おすすめ（食品／ファッション／美容／雑貨）」「よくある質問」「セール情報」などをカテゴリ分け
- **Xヘッダー画像／Instagramのプロフィール直下ピン投稿**：自己紹介投稿を固定し、初訪問者に「何を紹介しているアカウントか」が伝わるようにする

## 5. フェーズ2：自社EC移行版プロフィール（参考・将来差し替え用）

フォロワーが育ち自社EC移行のタイミングになったら、以下の方向に差し替える：

- 一人称を「私」から「当店」「私たち」に変更
- 「大人世代のくらし発見帖」→「大人のくらしセレクトショップ」等、自社ブランド名を主語にした文言に変更
- リンク欄を楽天ROOMから自社ECサイトURLに変更
- Instagramのカテゴリ設定を「ショッピング・小売」に変更
- アフィリエイト表記（PR）は自社商品のみになった時点で不要（他社商品の紹介を続ける場合は継続）
