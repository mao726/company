# SNSプロフィール文言テンプレート（X／Threads／Instagram）

対象アカウント：新規開設した X（旧Twitter）、Threads、Instagram
ターゲット：40〜58歳
取扱ジャンル：食品・グルメ／ファッション・アパレル／美容・健康／生活雑貨・インテリア
ポジショニング（フェーズ1）：**「かおり」個人としてファンをつける楽天アフィリエイト紹介アカウント**（アイコンは本人写真）
将来（フェーズ2）：フォロワーが育った段階で自社ECブランドへ移行予定

> 同ジャンルの成長アカウント調査（`docs/sns-account-research.md`）から、「ファンは商品ではなく“人”につく」「アイコンは自分の顔に相当する要素として本人写真・似顔絵が推奨される」という知見が得られたため、店・キュレーターという体裁ではなく個人名「かおり」を主語にした一人称発信に変更した。
> `[楽天ROOM等のリンク]` は仮のプレースホルダーです。リンクが決まり次第、該当箇所を差し替えてください。

## 共通の設計方針

- 主語は「私（かおり）」の一人称。店舗・ブランドではなく個人として発信する
- アイコンは3媒体共通で**本人写真**を使用（統一感を出し、覚えてもらいやすくする）
- 何を紹介するアカウントか（40〜58歳向け・食品/ファッション/美容/雑貨）を最初の1文で明示する
- 絵文字は1〜2個までに抑え、年代に合わせて落ち着いたトーンにする
- 完璧に作り込んだ発信より、等身大・人間味のある実体験ベースの発信を優先する（調査で確認された成長要因）
- 全アカウントでプロフィール文の核（コンセプト文）は統一し、媒体特性に合わせて末尾の一文だけ変える
- **アフィリエイト表記を必ず含める**：「PR」「楽天アフィリエイト」等の文言をプロフィール文またはリンク前に明記し、景品表示法（ステマ規制）に対応する

**名前：**
`かおり｜40代からのくらし発見`

**プロフィール文（160字以内）：**
```
かおりです。40〜50代の暮らしに役立つ、食品・ファッション・美容・生活雑貨を紹介しています。
実際に自分で使ってよかったものだけを発信中。
楽天のお得情報やセールもお知らせします。
※紹介リンクは楽天アフィリエイトを含みます（PR）
```

**アイコン：** 本人写真
**ウェブサイト欄：** `[楽天ROOM等のリンク]`
**場所：** 記載なし（個人発信のため所在地は不要）

## 2. Threads

**名前：**
`かおり｜40代からのくらし発見`

**プロフィール文（Instagramと連携されるため簡潔に）：**
```
かおりです。40代からの暮らしに、ちょうどいいものを。
自分が実際に使ったものだけを紹介しています（楽天アフィリエイトPR含む）。
```

**アイコン：** 本人写真（Xと同一画像）

**運用メモ：** Threadsはフォロワーが少なくても非フォロワーに配信されやすいアルゴリズムのため、商品紹介だけでなく日常投稿を混ぜて「かおりという人」を知ってもらうことを優先する。プロフィールやピン留め投稿から楽天ROOMへ誘導する導線役として活用する。

## 4. アイコン・ヘッダー画像の統一方針

- **アイコン**：3媒体共通で本人写真1枚に統一する。清潔感があり、笑顔が伝わる自然な写真を推奨（加工しすぎない方が信頼感につながる、と調査結果でも指摘あり）
- **Instagramハイライトカバー**：「かおりです」「ジャンル別おすすめ（食品／ファッション／美容／雑貨）」「よくある質問」「セール情報」などをカテゴリ分け
- **Xヘッダー画像／Instagramのプロフィール直下ピン投稿**：自己紹介投稿を固定し、初訪問者に「かおりが何者で、何を紹介しているか」が伝わるようにする

## 5. フェーズ2：自社EC移行版プロフィール（参考・将来差し替え用）

フォロワーが育ち自社EC移行のタイミングになったら、以下の方向に差し替える：

- 「かおり」個人の発信は継続しつつ、「かおりが手がけるブランド〇〇」という形で自社ブランドを紐づける（個人の信頼を資産として引き継ぐ）
- リンク欄を楽天ROOMから自社ECサイトURLに変更（または併記）
- Instagramのカテゴリ設定を「ショッピング・小売」に変更
- アフィリエイト表記（PR）は自社商品のみになった時点で不要（他社商品の紹介を続ける場合は継続）
