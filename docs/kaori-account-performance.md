# かおりアカウント実績トラッキング

Threads実アカウント（@kaori.726726）の実績を毎週月曜日に記録する定点観測メモ。

フォロワー数の推移、投稿ごとのいいね・コメント数、コメント/いいね比率から見える傾向、気づいた問題点（トーンのブレ、パターンの偏り、エンゲージメントベイトのリスクなど）を記録していく。

## 記録フォーマット

- 日時
- フォロワー数（前回からの増減）
- 直近投稿の数値一覧（投稿内容・経過時間・いいね・コメント・コメント/いいね比率）
- 分析（伸びているパターン、注意点、前回からの変化）
