# Threads 伸びているユーモア投稿 定点観測メモ

毎日10時・15時・21時に、その時点でThreads上で伸びている（反応が良い）ユーモア系投稿の傾向をリサーチし、ここに追記していく。

このセッションは直接Threadsを閲覧できないため、Web検索経由で得られる話題・まとめ・引用情報をもとに間接的に傾向を掴む形で調査する（`sns-strategy-40-58.md`の「投稿作成フロー」と同じ制約）。

## 記録フォーマット

- 日時
- 投稿内容の要約（引用できる範囲で）
- 伸びている理由の分析
- かおりへの適用アイデア（あれば）
