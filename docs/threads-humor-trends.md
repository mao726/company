# Threads 伸びているユーモア投稿 定点観測メモ

毎日10時・15時・21時に、その時点でThreads上で伸びている（反応が良い）ユーモア系投稿の傾向をリサーチし、ここに追記していく。

このセッションは直接Threadsを閲覧できないため、Web検索経由で得られる話題・まとめ・引用情報をもとに間接的に傾向を掴む形で調査する（`sns-strategy-40-58.md`の「投稿作成フロー」と同じ制約）。

## 記録フォーマット

- 日時
- 投稿内容の要約（引用できる範囲で）
- 伸びている理由の分析
- かおりへの適用アイデア（あれば）

## 2026-10-02 09:53 JST

- 「限界ハチワレ」投稿が拡散：疲れ切った様子を可愛いキャラクターに重ねた"限界"ネタ。「面白い」「かわいい」「天才」等のコメントで拡散。
  - 伸びている理由：誰もが経験する「もう限界…」という疲労感を、深刻にならずキャラクターの可愛さで中和しているのが共感ポイント。
  - かおりへの適用：疲労感を深刻にならず、ちょっと可愛く/面白く表現する投稿（例：「夜ご飯作る気力ゼロの日、ついに○○した」のような軽い自虐＋救済オチ）が等身大トーンと相性良さそう。
- 翻訳ミスでシーサーが「赤ちゃん豚ライオン」＋「電気拷問」に変換される珍事が拡散。
  - 伸びている理由：予想外の誤訳が生む純粋な不条理さ・シュールさ。かおりの発信ジャンルとは直接結びつきにくい。
- 豆腐の日・ドレンチェリー等、季節行事や懐かしアイテムをきっかけにした「あるあるレシピ共有」系も反応あり（共感止まりで拡散力は上記より弱め）。
