# 40〜58歳ターゲット SNS運用・投稿戦略（X／Threads／Instagram）

対象：新規開設した X（旧Twitter）、Threads、Instagram の3アカウント
ターゲット層：40〜58歳（就業中の会社員・管理職・子育て後期〜卒業世代・親の介護世代を含む）

## 0. フェーズ方針

自社EC事業をいきなり前面に出すのではなく、**まず楽天アフィリエイトでの商品紹介を軸にフォロワー・信頼を獲得し、その後自社ECへ移行する**2段階方針で進める。

| フェーズ | 時期目安 | 目的 | 収益・導線 |
|---|---|---|---|
| **フェーズ1：アフィリエイト期** | 開設〜フォロワーが一定数育つまで | アカウントの信頼構築、フォロワー獲得、投稿の型・反応の良いテーマを見極める | 楽天アフィリエイト（楽天ROOM・アフィリエイトリンク）経由の紹介収益 |
| **フェーズ2：自社EC移行期** | フォロワー・エンゲージメントが安定してから | 自社ブランド・商品の認知拡大〜購入・リピート促進 | 自社ECサイトへの導線に切り替え／併用 |

- フェーズ1では「店」ではなく「40〜58歳向けに役立つ商品を紹介する個人（キュレーター）アカウント」という立ち位置で運用する
- フェーズ1で得たフォロワーの反応データ（どんな商品・テーマが伸びたか）をフェーズ2の自社EC商品選定・訴求軸に活用する
- **アフィリエイト表記は必須**：景品表示法（ステルスマーケティング規制）により、紹介・宣伝であることを明示する必要がある。投稿本文またはハッシュタグに「#PR」「#広告」「#楽天アフィリエイト」等を明記する

## 1. ターゲット層の特性

- **情報収集習慣**：検索エンジンやテレビ・雑誌からの流入に加え、SNSでの「実体験レビュー」「専門家の解説」を重視する傾向。派手な演出より信頼性・実用性を評価する。
- **可処分時間**：通勤時間・夜間（21〜23時）・休日午前に閲覧が集中しやすい。
- **購買行動**：即決より比較検討期間が長い。価格だけでなく品質・安全性・アフターサポートを重視。
- **プラットフォーム利用傾向**：
  - X：ニュース・時事・実用情報の収集、企業アカウントのフォローは目的が明確な場合が多い
  - Instagram：ライフスタイル・グルメ・旅行・健康・ファッション（大人向け）の情報収集
  - Threads：X的な即時性とInstagram的な柔らかいトーンの中間。まだ企業活用が少なく先行者メリットがある

## 2. トーン＆マナー（共通方針）

- 誇張表現・若者言葉・過度な絵文字は避け、「信頼できる専門店・スタッフ」のトーンで統一する
- 一人称は「当店」「私たち」など落ち着いたトーンにし、丁寧語をベースにする
- 見た目の派手さより「情報の正確さ」「具体的な数字・根拠」を前面に出す
- 家族（子ども・配偶者・親）との関わりに触れるエピソードは共感を得やすい

## 3. プラットフォーム別運用方針（フェーズ1：アフィリエイト期）

### X（旧Twitter）
- **役割**：楽天セール情報・お得な商品情報の即時発信、フォロワーとの日常的な接点作り
- **投稿頻度**：1日1〜2回（朝8時台／夜21時台を軸に）
- **content例**：
  - 楽天お買い物マラソン・スーパーセール等のタイミング紹介
  - 実際に使ってよかった商品の一言レビュー＋アフィリエイトリンク
  - 業界の時事ネタ＋暮らしに役立つ関連コメント
- **注意点**：アフィリエイトリンクを貼る投稿には必ず「#PR」等の表記を入れる

### Threads
- **役割**：紹介者本人の人柄・暮らしぶりを伝える柔らかい発信、コミュニティ形成
- **投稿頻度**：週3〜5回
- **content例**：
  - 日常の中で商品を選んだ理由・使ってみた感想
  - フォロワーとの対話形式の投稿（「こういうのある？」に回答するなど）
  - Instagram投稿のこぼれ話
- **注意点**：まだユーザー層・機能が流動的なため、実験的な投稿で反応を見ながら調整する

### Instagram
- **役割**：ビジュアルで商品の魅力・使用シーンを伝え、楽天アフィリエイトリンク（楽天ROOM等）への導線を作る
- **投稿頻度**：フィード週2〜3回、ストーリーズ毎日、リール週1〜2回
- **content例**：
  - 商品の使用シーン（40〜58歳の実生活シーンを意識）
  - ビフォーアフター、活用術、Q&A形式
  - プロフィールリンク（楽天ROOM／リンクまとめ）への誘導文言を明記
- **注意点**：フィルター過多・過剰な加工は信頼を損ねやすいため、自然な写真を優先する。ストーリーズ・投稿のアフィリエイトリンクには「#PR」表記を徹底

## 4. コンテンツテーマ（フェーズ1：アフィリエイト軸）

| テーマ | 目的 | 主な発信先 |
|---|---|---|
| 商品の実体験レビュー・根拠 | 信頼構築、比較検討層への訴求 | Instagram、X |
| セール・タイムセール情報 | クリック・購入喚起 | X、Instagramストーリーズ |
| 使い方・活用シーン提案 | 購買後押し | Instagram（リール／ストーリーズ） |
| 紹介者自身の暮らし・エピソード | ファン化・フォロー継続動機 | Threads |
| フォロワーとの対話・Q&A | エンゲージメント向上 | X、Threads |

将来フェーズ2（自社EC移行後）は、上記に「自社ブランドストーリー」「自社商品限定の品質・安全性訴求」「カスタマーサポート」等のテーマを追加する。

## 5. 運用体制・KPI（案）

- **フェーズ1 KPI（〜フォロワー育成期）**：フォロワー数、エンゲージメント率（いいね・保存・コメント）、プロフィール／アフィリエイトリンクのクリック数、アフィリエイト成果件数
- **フェーズ1→2移行の目安**：各アカウントのフォロワー数・エンゲージメント率が一定水準に達し、投稿の反応傾向（伸びる商品ジャンル・訴求軸）が把握できた段階で移行を検討
- **フェーズ2 KPI（自社EC移行後）**：自社ECサイトへの流入数、SNS経由のコンバージョン数・売上
- **運用フロー**：投稿カレンダーを月次で作成 → 週次で数値レビュー → 反応の良かった投稿傾向を次月に反映

## 6. 次のステップ（提案）

1. 3アカウントのプロフィール文言・アイコン・ヘッダー画像の統一デザイン作成（アフィリエイト期向け）
2. 初回投稿（自己紹介・挨拶投稿）の文案作成
3. 月次投稿カレンダーのテンプレート作成
4. ハッシュタグ・キーワードの選定（40〜58歳層に届きやすい語彙の洗い出し）
5. フォロワー数・エンゲージメントの移行判断基準（フェーズ2着手のトリガー）を具体的な数値で設定
