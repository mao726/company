# 受託ビジネス 市場調査（2026-10-10）

[30日事業計画](./jobs-30day-plan.md)の受託事業について、実際の案件・出品データから需要・単価・競争度を調べた結果。

## 調査方法

- **CrowdWorks**：公開されている案件検索で、16キーワード×最大3ページの新着案件を収集（重複を除き921件、9/26〜10/10掲載分）。応募者数・予算・報酬形式を集計。
- **ココナラ**：20キーワードで検索し、上位60件の出品の価格と評価件数を収集（評価件数＝販売実績の目安）。
- ランサーズはアクセス制限（429）のため今回は対象外。手数料・規約は公開記事と公式情報で確認。

### わかったこと

- **LP・ホームページ制作は激戦**。「実績作り歓迎」のカフェHP制作（5〜10万円）に**115〜259人**、LP制作（1〜3万円）に**50〜130人**が応募している。実績ゼロの新規アカウントが普通に応募しても選ばれにくい。
- **「スプレッドシート」「Excel」案件の大半は自動化ではなく作業代行**（データ入力・転記・リサーチ・リスト作成）。単価1〜3万円、応募者10〜60人。AIで速く正確に処理でき、**ジョブスの得意分野**。
  - 例：PDF社内マニュアルをWordへ転記・編集（1.5万円、応募0〜39人）、Googleマップを使った企業情報リサーチ（1〜3万円、29人）、PDF資料→スプレッドシート転記（1〜3万円、10〜25人）
- **本格的な業務自動化・AI開発案件**（GAS・AIエージェント、15〜50万円）もあるが、応募70〜90人で経験者が選ばれやすい。
- **避ける案件**：問い合わせフォームへの一斉送信、DM大量送信、テレアポ、利用体験談（やらせの恐れ）、「高収入」系の勧誘。規約・法律・評判のリスクがある。

### 上位出品者の型

- **入口は安く、オプションで単価を上げる**：評価936件の「Google Apps Scriptで自動化します」は**3,000円**、評価1,847件の「Excel作業代行」は1万円。基本料金を安くして購入のハードルを下げ、内容に応じた見積・オプションで実単価を上げている。
- LP制作の最多評価（447件）は「ペライチで売れるLPを制作」**15,000円**。一方で15〜22万円の高単価出品も評価100件超あり、**価格帯が二極化**。
- **GAS・スプレッドシートは評価0件の出品が多い**。新規でも並べる余地がある（その分、差別化しないと埋もれる）。

## 3. 手数料・お金の流れ

| | 手数料（受注者側） | 振込手数料 |
|---|---|---|
| ランサーズ | 16.5%（税込） | 110〜550円 |
| クラウドワークス | 段階制5〜20%（一律11%に改定とする記事もあり、要確認） | 100〜500円 |
| ココナラ | 22%（税込） | 160円 |

- **振込までにタイムラグがある**（取引完了→振込申請→入金）。30日以内に受注・納品しても、入金は30日を過ぎる場合がある。成果は「取引完了した売上」で管理する。

## 4. 規約上の注意

- **AI利用**：クラウドワークスはAI利用を禁止していないが、**可否は案件ごと・発注者との取り決め次第**。利用を隠さないことが求められる。→ 提案時に「AIを活用し、人が確認して納品」と明記し、AI禁止の案件には応募しない。
- **ココナラ**：AIで自動生成したイラストの出品は原則不可（素材として一部使うのも不可）。文章や資料・ツールは可。→ **画像はAI生成を使わない**（自作の図・CSS・無料素材のみ）。
- **直接取引の禁止**：プラットフォームで出会った顧客をサイト外の取引に誘導するのは規約違反（アカウント停止の恐れ）。→ **月額保守もプラットフォーム内で契約する**。自社サイト経由の直接受注は、自社サイトで獲得した顧客だけに限る。

## 5. 戦略への反映

1. **本命を「LP制作」から「スプレッドシート・Excel・GAS（作業代行＋自動化）」に移す**。競争が緩く、AIで品質とスピードの差をつけやすく、月額契約（定期作業・保守）にもつながりやすい。
2. **ココナラでは入口価格3,000〜5,000円＋見積・オプション**で出品し、まず評価を集める。
3. **CrowdWorks／ランサーズでは「提案時に動く見本を添付」**して、実績ゼロの不利を補う（GASなら動くスクリプト、転記なら最初の数件を処理したサンプル、LPなら完成イメージ）。
4. **LP制作は続けるが2番手**。ココナラで15,000円〜の入口出品、CrowdWorksでは応募の少ない案件だけを選んで見本つきで提案。
5. **納品スピード（最短当日〜24時間）を最大の売り**にする。
