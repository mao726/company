# 技術的な判断の記録

重要な設計判断は、理由と影響範囲をここに記録する。状態は「提案」「承認」「却下」「置き換え」「要決定」のいずれか。
**「提案」「要決定」は未決定であり、事業責任者の承認前に実装の前提にしない。** 事業上の判断事項は `open-decisions.md`。
